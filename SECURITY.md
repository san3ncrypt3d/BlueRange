# Security policy

Please report vulnerabilities using GitHub's **Private vulnerability reporting** feature on this repository's Security tab. Do not open a public issue for an undisclosed vulnerability. Include impact, affected revision, reproduction details, and any suggested mitigation. Maintainers will acknowledge and coordinate remediation/disclosure through that private report.

BlueRange simulates defensive decisions and intentionally provides no offensive execution. Do not include live credentials, personal data, production logs, malicious payloads, or secrets in scenarios or reports.
