# Contributing

Contributions are welcome. Open an issue for substantial design changes, keep changes focused, and add behavior-first tests. Use Python 3.12+, install `.[dev]`, then run `ruff check .`, `mypy bluerange`, and `pytest`. Scenario telemetry must be synthetic and ground truth must remain in its protected file. By contributing, you agree that your work is licensed under Apache-2.0 and to follow the Code of Conduct.
